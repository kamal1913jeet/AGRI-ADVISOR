# 🌱 AI Agriculture Advisor

An intelligent Agriculture Advisory System built using **Python**, **Scikit-learn**, and **Streamlit** that assists farmers in selecting the most suitable crop based on soil and environmental conditions.

The application leverages Machine Learning to provide real-time crop recommendations, making farming decisions more accurate and data-driven.

---

## 📌 Project Overview

Agriculture plays a significant role in the economy, and choosing the right crop is essential for maximizing yield and minimizing losses.

This project predicts the most suitable crop using machine learning by analyzing important agricultural parameters such as:

- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- Soil pH
- Rainfall

The prediction helps farmers make informed cultivation decisions.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/kamal1913jeet/AGRI-ADVISOR.git
```

Move into the project directory

```bash
cd AI-Agriculture-Advisor
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run Streamlit

```bash
streamlit run app.py
```
